# Prudence — Web3 × Creative Portfolio

A premium, single-page portfolio built around:
- Web3 Business Development
- Promotion / Growth
- Motion Graphics
- Video Editing
- 3D Motion
- Creative Strategy

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.

## Replace the placeholders
1. Edit the `projects` array in `script.js`.
2. Replace project visual placeholders with real images/video thumbnails.
3. Update the email and social links in `index.html`.
4. Replace case-study placeholder copy with verified project details and metrics.
5. Add real project videos inside the project modal if desired.

## Visual system
Dark monochrome foundation, liquid-glass UI, restrained motion, editorial typography and a horizontal project slider. The page uses vanilla HTML/CSS/JS so it is easy to migrate into Next.js, React, Framer or another stack later.


## Video interaction
Each project card now supports:
- Click the video to play/pause.
- Dedicated circular play/pause button.
- Muted inline playback for the portfolio slider.
- Full native video controls inside the project detail view.
- Replace the files in `assets/videos/` with your real project videos.
